# SIH26092 Frontend

A dark, dashboard-style React interface for discovering government financial schemes, understanding eligibility, estimating EMI and finding channel partners.

## Main flow

Home → Profile → Results → Scheme Details → Partners → Partner Details

## Highlights

- Single profile form; no separate Details page.
- State and district selectors covering Indian states and Union Territories.
- Eligibility-first recommendations with reasons for ineligible schemes.
- Scheme details and EMI estimate using the requested amount already entered in the profile.
- Automatic location-based channel partner search with district/state fallback.
- Interactive Google Maps area for selected partners.
- Consistent dark dashboard visual system inspired by modern operations dashboards.
- Bold user-entered form text throughout the interface.
